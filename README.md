# Fireflies Transcript Downloader

A Python tool to download meeting transcripts from Fireflies.ai and save them to Google Drive.

## Overview

This project helps you automate the process of downloading transcripts from your Fireflies.ai meetings and organizing them in your Google Drive destination folder.

## Features

- Download transcripts from Fireflies.ai
- Authenticate with Google Drive
- Automatically organize transcripts in specified Google Drive folders
- Support for batch downloads

## Prerequisites

- Python 3.8+
- Fireflies.ai account with API access
- Google Cloud Project with Drive API enabled
- Google Drive API credentials

## Installation

```bash
pip install -r requirements.txt
```

## Configuration

1. Set up your Fireflies API credentials
2. Configure Google Drive API credentials
3. Specify your target Google Drive folder

## Usage

```bash
python fireflies_downloader.py
```
